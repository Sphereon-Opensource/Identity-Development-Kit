# W3C JSON-LD API vectors

Source: https://github.com/w3c/json-ld-api
Pinned commit: `ffdb326121ea89b7b8280e76a5caea923834bcef`

This directory contains a representative, offline subset of the official
`toRdf` vectors (0001, 0002, 0003, 0004, 0015, and 0026). The upstream W3C
Software and Document License is reproduced in `LICENSE.md`. No runtime
network access is used. The complete upstream corpus includes additional
algorithm groups and remains a follow-up conformance item.
