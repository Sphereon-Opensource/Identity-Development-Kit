# Module lib-data-store-okd-openapi

OpenAPI-generated client and model types for the OKD (Onderwijs Koppeling voor Documenten) Dutch MBO education document standard. Sources are generated from the upstream OKD OpenAPI spec at build time; there is no hand-written API surface.

This module is only relevant to integrations that speak the OKD protocol. It is consumed by `lib-data-store-blob-impl-okd` (the blob-store adapter) and `lib-data-store-okd-server` (the reference server).
