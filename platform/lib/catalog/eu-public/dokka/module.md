# Module lib-catalog-eu-public

Models, XML parsing and conformance validation for the EU wallet catalogues: the Catalogue of Attributes (CoA), the Catalogue of Schemes (CoS) and the List of Catalogues (LoC, a profile of ETSI TS 119 602). It also defines the read SPI and the external identifier method names that resolvers use to look catalogue entries up.

No network, signature or digest verification lives here; that belongs in the implementation module.
