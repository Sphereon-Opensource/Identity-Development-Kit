# Module Identity-Development-Kit (IDK)

The Identity Development Kit (IDK) is Sphereon's Kotlin Multiplatform library for building identity solutions.

## Overview

IDK provides core functionality for:

- **Cryptography** - Key management, signing, and verification (JOSE, COSE)
- **DIDs** - Decentralized Identifier creation, resolution, and management
- **Verifiable Credentials** - W3C VC/VP issuance and verification
- **mDL/mDoc** - ISO 18013-5 mobile document support
- **OpenID4VC** - OpenID for Verifiable Credentials protocols

## Platforms

IDK supports JVM, JavaScript/Node.js, iOS, and Linux targets.

## Getting Started

Add IDK dependencies to your project via Maven/Gradle from Sphereon's repository.

For more information, visit [docs.sphereon.com](https://docs.sphereon.com).
