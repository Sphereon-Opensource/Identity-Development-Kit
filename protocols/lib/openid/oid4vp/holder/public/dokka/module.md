# Module lib-openid-oid4vp-holder-public

Public API for the OID4VP holder (wallet) side. It defines the holder surface, the holder-side models, and the command bindings a wallet uses to respond to a verifier's authorization request.

Depend on this module from wallet or wallet-backend code that has to participate in OID4VP presentations. Runtime implementations live in `lib-openid-oid4vp-holder-impl`.
